# Optional interface patterns

- Use a compact summary with an expandable detail region for supporting evidence.
- Put advanced configuration behind a clearly named disclosure; preserve meaningful defaults and show validation beside the affected control.
- Use an icon toolbar for familiar actions, with accessible names, visible focus, and tooltips that work with keyboard focus.
- Use a table when users compare the same attributes across items. Offer a detail view for long explanations.
- For creative explainers, put narration in notes and keep only necessary labels and evidence on the canvas.
- Use one purposeful animation or state transition when it helps explain what changed. Prefer the project's existing motion adapter and honor reduced motion.

These are options. Choose according to the task and existing design; none requires a new dependency or a particular layout.
