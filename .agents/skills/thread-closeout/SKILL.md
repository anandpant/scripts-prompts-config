# Thread closeout

Confirm the requested outcome and report the result, relevant verification, deliverable links, and any remaining action succinctly.

For owned Git work, check local/unpushed changes, actual PR/CI/review state, and applicable deployment proof. Complete authorized merge and safe branch/worktree cleanup. Preserve unrelated work; do not make its publication or deletion a condition of closing an unrelated task.

For creative or non-Git work, inspect the final render, playback, document, or export and preserve the source assets in the project. No PR or worktree is required.

Keep ownership of active watchers and unfinished work. Hand them off explicitly rather than leaving orphaned processes. Suggest a learning or policy change only when it is useful; do not modify memory or automations without the user's request.

Archive only when the work is terminal, no user response or watcher ownership remains, and the app provides an archive tool. Do not invent an archive directive or require an unavailable tool to finish.
