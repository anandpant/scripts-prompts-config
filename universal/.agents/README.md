# Portable agent sources

Curated default skills are owned in the repository's `.agents/skills` directory.
Use `python3 universal/install-agent-defaults.py` to install them, then `--check`
to verify the live copies. Shared Codex behavior is in `universal/.codex/AGENTS.md`.
Remaining skills here are portable specialist backups, not a second source for
the curated defaults. Preserve explicit model choices and scope optional vendor
skills to relevant projects.
